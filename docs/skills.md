# AI Skills

在「设置 → Skills」或 AI 窗口顶栏的书本按钮打开管理界面。

Skill 文件统一放在**软件目录下的 `skills` 文件夹**。安装版为 exe 同级目录，便携版为原始 exe 同级目录，开发时为项目根目录。软件启动时自动创建此文件夹，管理界面显示完整路径，并提供「打开文件夹」按钮。

用户可以直接放入 `skills/<Skill 文件夹>/SKILL.md` 及其附带资料。刷新列表或发送对话时自动识别，无需再次导入；新发现的 Skill 默认停用，手动启用后即可使用。修改文件会在下一次发送时生效，移出 Skill 文件夹后不再加载。

- **添加本地目录**：选择一个 Skill 目录或包含多个 Skill 的集合，保留说明和附带文件。
- **添加本地文件**：选择 `SKILL.md` 或 ZIP。单独选择 Markdown 时只导入该文件。
- **在线安装**：粘贴 GitHub 仓库、`tree/<分支>/<目录>`、`blob/<分支>/…/SKILL.md` 链接，或 HTTPS 的 Markdown / ZIP 下载地址。GitHub 分支名目前不能包含 `/`；私有仓库鉴权暂不支持。
- 在线下载和本地导入都会写到 `skills/<Skill 名称>/`，保留 `SKILL.md` 和附带文件。不会覆盖已有文件夹；名称冲突时使用唯一的子目录名。
- 下载或导入后预览说明，选择需要的 Skill 并安装。安装默认停用，手动启用后从下一次发送生效，适用于所有 AI 配置。同名 Skill 需删除旧版本后重新安装。

标准目录示例：

```text
my-skill/
  SKILL.md
  references/
    guide.md
  scripts/
    example.py
```

`SKILL.md` 使用 UTF-8，并以 YAML 元数据开头：

```markdown
---
name: my-skill
description: 描述该 Skill 的用途及何时使用。
---

# 操作说明

按顺序列出步骤。附带资料使用包内相对路径，例如 references/guide.md。
```

支持单行、引号字符串，以及 `>` / `|` 的多行 description。其他元数据保留在正文文件中。
可以用 `examples/skills/chinese-writing` 体验本地导入。

启用工具时，AI 先获得 Skill 名称与描述，再使用 `read_skill` / `read_skill_file` 按需读取说明和文本资料。需要运行 Python 时调用 `run_skill_python`，脚本路径为 Skill 内的相对路径，参数按字符串数组传入。工作目录固定为 Skill 根目录，脚本可自行读取本地 `.env` 及附带资料。「询问」模式运行前逐次确认，「自动」模式直接运行；工具关闭时不会执行脚本。

Python 优先使用 Skill 自己的 `.venv` / `venv` 环境，否则自动查找本机 Python 3，包括 Windows 常见安装位置、`py -3` 和 PATH。虚拟环境及 `__pycache__` 不参与 Skill 资源扫描或导入。缺少解释器或依赖会显示具体错误，不会自动安装依赖。

脚本执行返回 stdout、stderr、退出码及运行时间，输出合计最多 64 KB，超出会标记截断。默认超时 120 秒，可指定 1–600 秒；点击停止会终止本地脚本进程树。脚本以当前用户权限运行，可访问本机文件和网络。终止本地脚本不能保证脚本已启动的远程操作也被停止。

工具关闭时，直接加载启用的说明，正文合计最多 128 KB，超出时在对话中提示。

Skill 文件固定保存在软件 `skills` 文件夹，启用状态和来源等记录保存在当前数据目录的 `ai/skills/<id>`。更改数据目录时迁移这些记录，Skill 文件仍留在软件旁。旧版保存在数据目录的 Skill 包会自动迁到统一目录，保留原 ID、来源和启用状态。列表中的「删除」会删除 `skills` 下对应的 Skill 文件夹及文件；从其他目录导入的原文件不会被删除。

限制：最多安装 100 个、同时启用 32 个；每次下载最多 30 MB，包内最多 2000 个条目、单文件 4 MB、总计 20 MB；`SKILL.md` 最多 64 KB。符号链接、路径穿越、加密 ZIP 和特殊文件会被拒绝。
